🎯 Descripción del Sistema

¿Qué hace este sistema?

Este sistema utiliza OCR (Reconocimiento Óptico de Caracteres) con Tesseract para leer placas vehiculares desde imágenes y verificar si están autorizadas para ingresar al estacionamiento del CBTis 144. El proceso incluye preprocesamiento de imagen, extracción de texto y validación contra una lista de placas autorizadas.

💻 Código Completo del Sistema OCR

import cv2
import pytesseract

# Configurar ruta de Tesseract
pytesseract.pytesseract.tesseract_cmd=r"C:\Users\MATUTINO\AppData\Local\Programs\Tesseract-OCR\tesseract.exe"

# Lista de placas aceptadas en el estacionamiento del CBTis144
placas_autorizadas=['XYZ789','DMB-123','QWE987','DLP876']

# Cargar placa al leer
placa=cv2.imread("placa1.jpg")
placanue=cv2.resize(placa,(1000,400))

# Convertir a escala de grises
placa_gris=cv2.cvtColor(placanue,cv2.COLOR_BGR2GRAY)

# Separamos el fondo con el texto (binarización)
placa_res=cv2.threshold(placa_gris,120,255,cv2.THRESH_BINARY)[1]

# Configurar OCR
texto_placa=pytesseract.image_to_string(placa_res, lang="spa")

# Limpiar la cadena de texto
texto_limpio=texto_placa.strip().replace(" ","_")

# Buscar la placa en la lista autorizada
if texto_limpio in placas_autorizadas:
    print("ACCESO PERMITIDO!!,\n Bienvenido al estacionamiento del CBTis 144")
else:
    print("ACCESO DENEGADO - Placa no autorizada")

# Imprimimos el texto detectado
print("Texto detectado:")
print(texto_placa)

# Mostrar imagen procesada
cv2.imshow("Imagen analizada",placa_res)
cv2.waitKey(0)
cv2.destroyAllWindows()

🔄 Flujo del Proceso

Paso 1: Carga y Redimensionamiento

Se carga la imagen de la placa y se redimensiona a 1000x400 píxeles para optimizar el procesamiento.

Paso 2: Conversión a Escala de Grises

La imagen se convierte a escala de grises para simplificar el análisis y mejorar la detección de texto.

Paso 3: Binarización

Se aplica un umbral (threshold) de 120 para separar el texto del fondo, creando una imagen binaria (blanco y negro).

Paso 4: Extracción de Texto (OCR)

Tesseract analiza la imagen binaria y extrae el texto de la placa vehicular.

Paso 5: Validación

El texto limpio se compara con la lista de placas autorizadas para permitir o denegar el acceso.

📚 Glosario de Librerías y Funciones

cv2 (OpenCV)

Librería de visión por computadora que permite procesar y manipular imágenes. Se usa para leer, redimensionar, convertir colores y aplicar operaciones de procesamiento de imagen.

pytesseract

Wrapper de Python para Tesseract OCR, una herramienta de código abierto que extrae texto de imágenes. Es muy preciso para reconocer texto impreso, incluidas placas vehiculares.

cv2.imread()

Lee una imagen desde un archivo y la carga en memoria como un array de NumPy. La imagen se carga por defecto en formato BGR (Blue, Green, Red).

cv2.resize()

Cambia el tamaño de una imagen a las dimensiones especificadas. Se usa para estandarizar el tamaño de las imágenes antes del procesamiento OCR.

cv2.cvtColor()

Convierte una imagen de un espacio de color a otro. En este caso, convierte de BGR a escala de grises (GRAY) para simplificar el procesamiento.

cv2.threshold()

Aplica binarización a una imagen en escala de grises. Los píxeles por debajo del umbral (120) se vuelven negros y los superiores se vuelven blancos. Esto separa el texto del fondo.

pytesseract.image_to_string()

Función principal de OCR que analiza una imagen y extrae todo el texto detectado como una cadena. El parámetro 'lang' especifica el idioma para mejorar la precisión.

strip()

Elimina espacios en blanco, saltos de línea y tabulaciones al inicio y final de una cadena. Limpia el texto extraído por OCR.

replace()

Reemplaza todas las ocurrencias de un carácter o subcadena por otro. Se usa para normalizar el formato de las placas (espacios por guiones bajos).

cv2.imshow()

Muestra una imagen en una ventana. Se usa para visualizar el resultado del procesamiento de la imagen antes de extraer el texto.

cv2.waitKey()

Espera a que el usuario presione una tecla. Con el argumento 0, espera indefinidamente. Mantiene la ventana de imagen abierta hasta que se presione una tecla.

cv2.destroyAllWindows()

Cierra todas las ventanas de OpenCV abiertas. Se usa para limpiar y liberar recursos después de mostrar las imágenes.

in (operador)

Verifica si un elemento está presente en una lista, tupla, conjunto o cadena. Retorna True si el elemento existe, False en caso contrario.
