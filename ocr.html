🎯 Descripción del Sistema

¿Qué hace este sistema mejorado?

Este sistema avanzado procesa múltiples imágenes de placas vehiculares en un solo ciclo, generando un reporte completo de todas las placas analizadas. Incluye validación contra placas autorizadas, manejo de errores para imágenes no encontradas, y un resumen final con estadísticas de placas leídas y pendientes.

✓ Procesamiento en lote: Analiza múltiples imágenes automáticamente
✓ Control de errores: Maneja imágenes no encontradas sin detener el programa
✓ Limpieza avanzada: Elimina espacios, saltos de línea y caracteres especiales
✓ Reporte detallado: Muestra placas leídas y placas restantes por escanear

💻 Código Completo del Sistema OCR Múltiple

import cv2
import pytesseract

# Ruta del ejecutable de Tesseract
pytesseract.pytesseract.tesseract_cmd = r"C:\Users\MATUTINO\AppData\Local\Programs\Tesseract-OCR\tesseract.exe"

# Lista de placas autorizadas
placas_autorizadas = ['XYZ789', 'DMB-123', 'QWE987', 'DLP876', 'VHW573']

# Lista de imágenes a analizar
imagenes_placas = ["placa1.jpg", "placa3.png"]

# Lista para guardar placas leídas
placas_leidas = []

for archivo in imagenes_placas:
    # Cargar y procesar imagen
    placa = cv2.imread(archivo)
    if placa is None:
        print(f"❌ No se pudo cargar la imagen: {archivo}")
        continue

    placanue = cv2.resize(placa, (1000, 400))
    placa_gris = cv2.cvtColor(placanue, cv2.COLOR_BGR2GRAY)
    placa_res = cv2.threshold(placa_gris, 120, 255, cv2.THRESH_BINARY)[1]

    # Leer texto con OCR
    texto_placa = pytesseract.image_to_string(placa_res, lang="spa")

    # Limpiar texto
    texto_limpio = texto_placa.strip().replace(" ", "").replace("\n", "").replace("_", "")

    print(f"\n📷 Imagen: {archivo}")
    print(f"Texto detectado: {texto_limpio}")

    if texto_limpio in placas_autorizadas:
        print("✅ ACCESO PERMITIDO: placa autorizada")
        placas_leidas.append(texto_limpio)
    else:
        print("❌ ACCESO DENEGADO: placa no autorizada")

    cv2.imshow(f"Placa analizada - {archivo}", placa_res)
    cv2.waitKey(0)

cv2.destroyAllWindows()

print("\n----- RESULTADOS -----")
print(f"Placas leídas: {placas_leidas}")

placas_restantes = [p for p in placas_autorizadas if p not in placas_leidas]
print(f"Placas restantes (no escaneadas): {placas_restantes}")

🔄 Flujo del Proceso Múltiple

Paso 1: Inicialización

Se configuran las placas autorizadas (5 en total), las imágenes a procesar y una lista vacía para almacenar las placas leídas exitosamente.

Paso 2: Ciclo For - Procesamiento Iterativo

El programa itera sobre cada imagen en la lista imagenes_placas, procesando cada una de forma secuencial.

Paso 3: Validación de Carga

Antes de procesar, verifica si la imagen existe. Si imread() retorna None, muestra un error y continúa con la siguiente imagen usando continue.

Paso 4: Preprocesamiento de Imagen

Cada imagen válida pasa por: redimensionamiento (1000x400), conversión a escala de grises, y binarización con threshold.

Paso 5: Extracción y Limpieza de Texto

Tesseract extrae el texto, luego se eliminan espacios, saltos de línea (\n) y guiones bajos para normalizar el formato.

Paso 6: Validación y Registro

Si la placa limpia está en placas_autorizadas, se agrega a placas_leidas usando append().

Paso 7: Reporte Final

Al terminar el ciclo, se genera un reporte con las placas leídas y las placas restantes (usando list comprehension).

📚 Glosario de Funciones Nuevas y Avanzadas

for ... in ...

Estructura de control que itera sobre cada elemento de una lista (o cualquier iterable). En este caso, procesa cada nombre de archivo en imagenes_placas uno por uno.

is None

Operador de comparación que verifica si una variable tiene el valor especial None (nulo en Python). Se usa para detectar errores cuando imread() no puede cargar una imagen.

continue

Palabra clave que salta inmediatamente a la siguiente iteración del ciclo, omitiendo todo el código restante en la iteración actual. Útil para manejar errores sin detener el programa completo.

append()

Método de listas que agrega un elemento al final de la lista. En este código, añade las placas autorizadas detectadas a la lista placas_leidas para generar el reporte final.

replace()

Método de cadenas que reemplaza todas las ocurrencias de un substring por otro. Se usa encadenado tres veces para eliminar espacios, saltos de línea (\n) y guiones bajos del texto OCR.

f-strings (f"...")

Formato moderno de cadenas en Python que permite insertar variables directamente usando {variable}. Ejemplo: f"Imagen: {archivo}" reemplaza {archivo} con el nombre del archivo actual.

List Comprehension

Sintaxis compacta para crear listas: [expresión for item in lista if condición]. Se usa para generar placas_restantes filtrando las placas que NO están en placas_leidas.
